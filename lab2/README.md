# Лабораторная работа №2

Макеев Илья Михайлович, М8О-209БВ-25. Вариант 20.

Найти три точки в пространстве, образующие треугольник максимальной площади.
Программа выполняет последовательный и параллельный поиск с POSIX Threads.

## Сборка и запуск

Из корня репозитория:

```sh
cd lab2
cc -O2 -std=c11 -Wall -Wextra -Wpedantic main.c -o lab2 -pthread -lm
./lab2 -t 10 -n 2000
```

`-t` — число потоков, включая основной (от 1 до 1024).
`-n` — число точек (от 3 до 5000). Порядок ключей: сначала `-t`, затем `-n`.
Точки создаются программой; обе версии обрабатывают одинаковый массив.

Программа выводит время обеих версий в миллисекундах, максимальную площадь,
номера трёх точек, ускорение и эффективность.

Ускорение: `S = Ts / Tp`. Эффективность: `E = S / p`.
`Ts` — последовательное время, `Tp` — параллельное время, `p` — число потоков.

Подробное описание, таблицы измерений и выводы — в [отчёте](209_Макеев_Лаб2.pdf).
