# Лабораторная работа №1

**Вариант 20**

## Задание

Родительский процесс принимает от пользователя строки произвольной длины.
Строки длиной больше 10 символов отправляются в pipe2, остальные — в pipe1.
Дочерние процессы инвертируют строки и пишут результат в свои файлы.

## Состав

- parent.c — родительский процесс
- child.c — дочерний процесс

## Как работает

- parent читает строки из stdin.
- Если длина строки больше 10 символов — пишет в pipe2, иначе в pipe1.
- child читает строки из своего канала, переворачивает их и пишет в файл,
  имя которого было задано при запуске.
- parent дожидается завершения обоих потомков через waitpid.

## Пример

Ввод:

    out1.txt
    out2.txt
    hello
    this string is longer than ten characters
    world

Файл out1.txt:

    olleh
    dlrow

Файл out2.txt:

    sretcarahc net naht regnol si gnirts siht

## Системные вызовы

fork, pipe, dup2, open, close, execl, waitpid, signal.

## Обработка ошибок

Все системные вызовы проверяются через perror. При ошибке процесс
завершается с ненулевым кодом. Родитель корректно закрывает дескрипторы
и проверяет статус завершения потомков (WIFEXITED, WEXITSTATUS).
