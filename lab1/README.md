# Лабораторная работа №1

**Вариант 20**

## Задание

Родительский процесс принимает от пользователя строки произвольной длины.
Строки длиной больше 10 символов отправляются в pipe2, остальные — в pipe1.
Дочерние процессы инвертируют строки и пишут результат в свои файлы.

## Состав

- parent.c — родительский процесс
- child.c — дочерний процесс
- io_utils.h — общие функции чтения, записи и вывода ошибок

## Сборка и запуск

Из корня репозитория:

```sh
cd lab1
cc -std=c11 -Wall -Wextra -Wpedantic parent.c -o parent
cc -std=c11 -Wall -Wextra -Wpedantic child.c -o child
./parent
```

Программу нужно запускать из папки `lab1`: родитель ищет `./child` в текущей
папке. Сначала введи два имени выходных файлов, затем строки. Для завершения
ввода нажми Ctrl+D на пустой строке.

## Как работает

- parent читает строки из stdin.
- Если длина строки больше 10 символов — пишет в pipe2, иначе в pipe1.
- child читает строки из своего канала, переворачивает их и пишет в файл,
  имя которого было задано при запуске.
- parent дожидается завершения обоих потомков через waitpid.

## Пример

Ввод:

    out1.txt
    out2.txt
    hello
    this string is longer than ten characters
    world

Файл out1.txt:

    olleh
    dlrow

Файл out2.txt:

    sretcarahc net naht regnol si gnirts siht

## Системные вызовы

fork, pipe, dup2, open, close, execl, waitpid, signal.

## Обработка ошибок

Ошибки создания процессов и каналов, открытия файлов, перенаправления
дескрипторов и запуска дочерней программы выводятся через `print_error`.
При записи проверяется результат `write`, а прерывание `EINTR` обрабатывается
повтором. Родитель проверяет завершение потомков через `waitpid`,
`WIFEXITED` и `WEXITSTATUS`.
