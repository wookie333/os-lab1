# Лабораторная работа №3. Обмен через общую память

Макеев Илья Михайлович, М8О-209БВ-25. Вариант 20.

Родитель передаёт строки двум дочерним процессам. Каждый потомок переворачивает
полученную строку и записывает её в свой файл. Граница из первой работы —
10 байт без перевода строки. Для примеров используй ASCII: как и в первой
лабе, разворот побайтовый (буква в UTF-8 может занимать несколько байт).

## Сборка и запуск

Из корня репозитория:

```sh
cd lab3
cc -std=c11 -Wall -Wextra -Wpedantic parent.c -o parent -pthread
cc -std=c11 -Wall -Wextra -Wpedantic child.c -o child -pthread
./parent
```

Введи два разных имени выходных файлов, затем строки. Существующие выходные
файлы будут перезаписаны. Заверши ввод с помощью Ctrl+D на пустой строке.
На старых системах Linux при ошибке компоновки shm_open добавь `-lrt` в конец обеих команд сборки.

## Пример

```text
short.txt
long.txt
hello
0123456789
abcdefghijk
```

В `short.txt` появятся строки `olleh` и `9876543210`, в `long.txt` — `kjihgfedcba`.

## Обмен

В `parent.c` родитель создаёт по именованному объекту памяти и семафору
`ready` для каждого потомка. Третий семафор `ack` принимает подтверждения.
В имена входят PID родителя, назначение объекта, а для ресурсов пары — ещё и номер потомка.
Родитель запускает две копии `./child` и передаёт имена через аргументы.

Формат блока задан в `shared.h`. Оба процесса открывают один объект через
`shm_open` и отображают его с `mmap(..., MAP_SHARED, ...)`. Родитель записывает
блок, подаёт сигнал `ready` и ждёт `ack`. Потомок в `child.c` разворачивает блок,
пишет его в перенаправленный стандартный вывод и подтверждает запись. В каждый
момент отправлен только один блок, поэтому одного `ack` достаточно.

Большие строки передаются с конца блоками до 4096 байт. Пустая строка даёт
пустую строку в первом файле. Размер −1 означает конец ввода. Когда оба
потомка подключились, родитель снимает имена объектов; уже открытые объекты
доступны до освобождения ресурсов процессами.
