# Лабораторная работа № 4. Динамические библиотеки

Макеев Илья Михайлович, М8О-209БВ-25. Номер 20 в таблице задания соответствует функциям № 3 и № 8.

| Команда | Первая библиотека | Вторая библиотека |
| --- | --- | --- |
| `1 a b` | Число простых на отрезке [a, b] перебором делителей | То же число с помощью решета Эратосфена |
| `2 x` | Двоичная запись x | Троичная запись x |
| `0` | В программе runtime перейти ко второй библиотеке | В программе runtime вернуться к первой |

Границы отрезка — натуральные числа, 1 ≤ a ≤ b. Для перевода можно вводить ноль и отрицательные целые числа.

## Запуск

Из корня репозитория на macOS или Linux с компилятором C и GNU Make:

```sh
cd lab4
make
./runtime
```

Введи по очереди:

```text
1 1 10
2 10
0
2 10
```

Подсчёт даст 4 (простые числа 2, 3, 5 и 7). В первой библиотеке число 10 даст 1010. Команда 0 покажет имя второй библиотеки, и то же число даст 101. Для выхода нажми Ctrl+D на пустой строке.

Для программы № 1 запусти `./linked` в той же папке. Она напрямую вызывает функции первой динамической библиотеки, выбранной при компоновке. В `runtime` тот же обработчик команд вызывает функции по адресам, полученным через `dlsym`. Программа открывает библиотеки относительно текущей папки.

## Где искать код

- `lib1.c` и `lib2.c` — две реализации подсчёта простых.
- `convert.c` — перевод делением с остатком. Makefile задаёт BASE=2 для первой библиотеки и BASE=3 для второй. Строка хранится внутри библиотеки до следующего вызова или выгрузки.
- `lab.h` — сигнатуры функций. `commands.c` читает команды для обеих программ.
- `linked.c` и `runtime.c` — две точки входа.
